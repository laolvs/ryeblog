# 导航与友情链接 插件说明

本插件提供「导航」与「友情链接」两套能力，可独立使用，也可同时开启。

## 功能入口

后台「插件内容」→「导航与友情链接」，包含：
- **链接管理**：增删改友情链接 / 导航项（名称、URL、分组、排序、是否新窗口打开）。
- **分组管理**：把链接归入不同分组（如「友情链接」「站内导航」）。

## 模式选择

![导航与友情链接模式](docs/img/navlinks-arch.svg)

插件设置提供三个开关：

| 模式 | 展示位置 |
| --- | --- |
| 仅友情链接 | 展示在首页指定位置 |
| 仅导航 | 作为独立频道 + 博客顶部导航 |
| 两者都要 | 首页与独立频道都展示 |

## 数据存储

- `vd_nav_groups`：分组（名称、slug、排序）。
- `vd_nav_links`：链接（标题、URL、分组、排序、新窗口、是否启用）。

## 使用建议

- 友情链接适合放在首页侧边或页脚；
- 站点主导航建议用「仅导航」或「两者都要」，并配合主题在顶部渲染；
- 分组可用于区分「友情链接 / 站内导航 / 合作伙伴」等。

## 常见问题

- **链接不显示？** 检查链接是否「启用」，以及所属分组是否在主题中输出。
- **顺序怎么排？** 在链接管理里设置排序值，数值越小越靠前。
