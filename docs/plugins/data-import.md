# 数据导入 / 导出 插件说明

数据导入导出插件用于把其它博客系统的内容迁移到 RyeBlog，或把本站内容备份为可恢复的 SQL / XML 文件。

## 功能入口

后台「插件内容」→「数据导入 / 导出」，或访问 `admin/plugin-config.php?dir=data-import`。

## 整体流程

![数据导入流程](docs/img/import-flow.svg)

支持的数据源：
- **WordPress XML**（WXR 标准导出）
- **Typecho XML**
- **SQL 文件**（整库或单表导出，自动识别 WP / Typecho 结构）

导入时会依次完成：解析字段 → 下载正文远程图片到本地 → 作者映射 → 写入数据库。

## 导入选项

![作者映射](docs/img/author-map.svg)

- **作者映射**：源博客的作者名（常为 `admin` 或原博主）往往与本地账号对不上。导入后所有新文章会统一归属到你选定的本地用户（默认当前登录管理员），避免作者名不符需进数据库手工修改。该操作只改文章的作者署名，不影响任何登录账号。
- **下载远程图片到本地**：把正文中的外链图片下载到 `usr/uploads/import/`，并替换链接，避免图床失效。
- **保留原 slug**：保证文章 URL 与原博客一致。
- **跳过已存在的文章**：按 slug 去重，重复导入更安全。
- **导入评论**：是否一并迁移评论。

## 三个标签页

### 1. 导入
按上述流程把外部数据迁入。导入大文件会自动取消执行时间限制。

### 2. 导出
把本站内容导出为 SQL 文件（phpMyAdmin 可直接导入）或 XML。包含：
- 分类、标签、文章（含独立页面）、文章-标签关联、评论；
- 站点设置（仅白名单内的展示类选项，不含账号密码等敏感数据）。

可选「导出时先 DELETE 整表」，便于整站覆盖式恢复。

### 3. 修复图片
扫描全部文章正文，把其中的远程图片下载到本地并替换 URL。适用于早期导入时图片未被本地化、或图床失效的情况。

## 重要安全说明

- 本插件**只处理内容数据**（分类 / 标签 / 文章 / 评论 / 设置），**不会读取或写入用户表（`vd_users`）**。
- 即使误传入包含 `vd_users` 的整库 SQL，导入器也会自动跳过用户 / 管理员等敏感表的写语句，管理员账户不会被替换。
- 作者映射功能同样**不写 `vd_users`**：它只把 `vd_posts.author` 这个署名字符串统一改成你选定的本地用户名，绝不会改动登录账号、密码或权限。
- `$author` 字段的默认值 `admin` 只是「文章作者署名」的展示文字，并非后台登录账号。

## 常见问题

- **修复图片点了没反应？** 多半是正文已无远程图片（导入时已本地化）。可先确认文章里是否还包含外链 `<img>`。
- **导入后图片 404？** 检查 `usr/uploads/import/` 目录是否存在且可写。
- **导入后作者对不上？** 使用「作者映射」选项，见上文流程图。
