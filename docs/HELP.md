# RyeBlog 后台帮助文档

欢迎使用 RyeBlog。本文档帮助你快速上手后台各项功能；所有文档均为图文形式，配合示意图更直观。

![帮助文档随处可达](docs/img/help-overview.svg)

> 💡 提示：帮助文档在「仪表盘横幅」「每个后台页底部」「登录页」三处均可一键打开；插件说明在「插件管理」列表的「说明」按钮。

## 后台总览

登录后默认进入**仪表盘**，可看到文章 / 页面 / 分类 / 标签 / 评论的数量概览，以及醒目的「帮助文档 / 授权协议」入口。

左侧导航包含：写文章、文章管理、分类管理、评论管理、附件管理、菜单管理、侧边栏管理、插件管理、插件内容、主题管理、站点设置。

## 快速开始

### 1. 写第一篇文章
进入「写文章」：
- 填写**标题**、**正文**（支持 Markdown / HTML）。
- **SEO 设置**默认展开：文章摘要、SEO 描述均为单行，SEO 关键词框已压缩高度。
- 可拖拽上传**附件**。

### 2. 从旧博客迁移（导入）
如果你有 WordPress / Typecho 的数据，使用「插件内容 → 数据导入 / 导出」即可迁移。详见 [数据导入 / 导出说明](docs.php?doc=plugins/data-import)。

![数据导入流程](docs/img/import-flow.svg)

### 3. 管理导航与友情链接
需要顶部导航或首页友情链接？启用「导航与友情链接」插件，在「插件内容」里管理分组与链接。详见 [导航与友情链接说明](docs.php?doc=plugins/nav-links)。

## 插件内容汇总页

后台新增「插件内容」入口，把各插件的内容添加 / 编辑入口集中在一处，不必再逐个找配置页。

![插件内容汇总](docs/img/plugin-hub.svg)

目前接入：**导航与友情链接**（链接管理 / 分组管理）、**数据导入 / 导出**（导入 / 导出 / 修复图片）。插件只需实现 `contentMenu()` 静态方法即可自动出现在此页。

## 常见问题

**Q：导入后作者对不上？**
A：源博客作者名（常为 admin 或原博主）与本地账号不同。导入时请用「作者映射」下拉框选好目标用户，导入后文章会自动归属到该用户，无需进数据库手工修改。见 [作者映射](docs.php?doc=plugins/data-import)。

**Q：修复图片点了没反应？**
A：多半是正文已无远程图片（导入时已自动本地化）。可先确认文章里是否还包含外链 `<img>`。

**Q：文档打开是乱码？**
A：正常不会。文档由图文渲染器统一输出 UTF-8；若看到原始 `# 标题` 文本，说明误点了 `.md` 源文件，请改用后台各处的文档链接。

## 安全须知

- 管理入口请从登录页进入，注意保管账号密码。
- 数据导入**只处理内容数据，不会改写用户表**，管理员账号安全。
- 定期用「数据导入 / 导出」做整站备份。
