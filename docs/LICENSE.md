# 授权协议

RyeBlog 全部源代码与文档采用 **GPL-3.0** 协议开源。

完整条款见仓库根目录的 [LICENSE.txt](../LICENSE.txt)。

## 为什么选择 GPL-3.0

- **防止闭源套壳**：任何人分发修改后的 RyeBlog（或其衍生作品），必须同样以 GPL 开放源代码——避免「换皮闭源商业售卖」。
- **生态保护**：与 WordPress / Typecho 等主流博客系统的 GPL 生态一致，贡献回流社区。
- **主题与插件**：作为衍生作品受 GPL 保护；作者原创主题/插件仍可保留版权声明并按 GPL 分发（与 WP 主题生态一致）。
- **商用友好**：GPL 允许收费分发与商业托管（SaaS），只要提供对应源代码获取途径。

第三方组件（vuecho 主题、RYE社区论坛插件、jQuery / fuse.js 等）沿用其各自与 GPL 兼容的授权，署名保留在原文件处。
