## 三、发现的问题与处理

### 已修复（3 项）

1. **未启用插件的配置页直接崩溃**
   - 现象：`plugin-config.php?dir=nav-links`（未激活）→ `Fatal: Table vd_nav_groups doesn't exist`
   - 修复：后台插件配置页检测插件启用状态，未启用时提示「请先启用插件」而非报错

2. **评论无垃圾防护（真实攻击已发生）**
   - 现象：走查期间发现 2 条 spam 机器人评论（英文垃圾 + 随机用户名）已入库
   - 修复：新增 `commentSpamCheck()`——同 IP 60 秒限频 + 中英文垃圾词黑名单（含「加V/发票/刷单/博彩/bitcoin/viagra/casino」等 30+ 词）
   - 验证：spam 词被拒（入库 0）✓；正常中文评论不受影响 ✓；`author_ip` 列随升级脚本自动添加

3. **伪静态规则不完整**（上一轮已修，归档于此）
   - 现象：开启伪静态后独立页/feed/sitemap 404（规则缺 page/feed/sitemap 转发）
   - 修复：完整路由规则 + 后台规则生成器补全

### 建议待办（未做）

| 项 | 说明 |
|---|---|
| 评论验证码 | 若垃圾评论仍多，可加简单算术验证码（后台开关） |
| 评论后台批量操作 | 目前单条审核/删除，量大时可加全选批量 |
| 注册开放策略 | 当前任何人可注册（role=user），如不想开放可在设置中加开关 |
