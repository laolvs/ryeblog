# RyeBlog 官方站「案例展示」频道内容规划

> 状态：v1 定稿（2026-08-19）｜落地对象：ryeblog.com 官方站案例展示频道（本地 verda 即官方站）

## 一、频道定位

- **唯一原则**：案例展示频道**只收录真实使用 RyeBlog 建成的网站**，宁缺毋滥，杜绝样板间式虚假案例。
- **与友情链接的边界**：案例 = 用 RyeBlog 建的站；友情链接 = 任意优秀站点（仅首页底部展示，不进入案例频道）。

## 三、案例分类规划（分组演进）

- **首期**：单分组「精选案例」，不做细分（案例少时分类无意义）。
- **中期**（案例 ≥ 10 时按类型拆组）：
  - 个人博客（最常见）
  - 文档 / 知识库站
  - 官方 / 机构站
  - 工具 / 门户站
- **卡片信息规范**（现有后台字段已支持）：站点名称、URL、一句话简介（≤30 字）、Logo（留空用首字母）、地区（国内/国外）、排序（推荐位）。
- 建议扩展字段（P1）：建站时间、使用的主题名、插件清单 —— 用于「案例详情」展示与筛选。

## 五、提交与审核机制（已落地）

1. **提交**：提交案例页 → 邮件 / 留言 → 7 个工作日内核验。
2. **审核标准**：站点运行 RyeBlog（页脚或源码可见标识）、可正常访问、内容合法合规、以原创为主。
3. **收录**：审核通过 → 加入「精选案例」分组。
4. **退出规则**：停止使用 RyeBlog 或长期无法访问 → 移出案例（可转为友链）。

## 六、运营节奏

- **频率**：每月集中审核一次提交；每收录一个案例，官方博客发「本月新案例」动态。
- **目标**：上线首月 3～5 个真实案例；半年 20+。
- **质量红线**：宁可案例区长期只有官方站 1 个，也**不收录非 RB 站**。
