# 存量站迁移方案：laolv.org + xuecha.org → RyeBlog

> 状态：方案 v1（2026-08-19）｜决策人：老吕（已拍板两站均迁）｜落地代码：`C:\xampp\htdocs\verda`

## 一、迁移目标

把两个存量站平滑迁到 RyeBlog，域名不变、内容全量、URL 尽量一致：

| 站点 | 现状 | 迁入后 |
|---|---|---|
| laolv.org | WordPress（PHP 8.3.30 + Site Kit，Cloudflare 代理），茶文化个人站 | RyeBlog + 个人博客主题 |
| xuecha.org | Typecho 1.3.0（Cloudflare 代理），茶学文档主题站 | RyeBlog + 文档主题（对齐原 Vuecho 风格） |

迁移完成后两站即成为官方站案例频道的首批真实案例。

## 二、工具链（已就绪，无需开发）

RyeBlog `data-import` 插件（v2.0.0）直接覆盖全部迁移能力：

| 能力 | 说明 | 两站适用 |
|---|---|---|
| WordPress 导入 | WXR XML（标准导出）或 SQL 自动识别 | laolv.org |
| Typecho 导入 | XML 或 SQL 自动识别 | xuecha.org |
| 远程图片本地化 | 正文外链图片下载到 `usr/uploads/import/` 并替换链接 | 均适用 |
| 保留原 slug | 文章 URL 与原站一致，避免 404 | 均适用 |
| 作者映射 | 源博客作者统一归属到选定本地账号（不改 vd_users） | 均适用 |
| 评论迁移 | 文章评论一并导入 | 均适用 |
| slug 去重 | 重复导入安全，可重跑 | 均适用 |
| 修复图片 | 导入后兜底扫描正文远程图片 | 均适用 |

> 安全边界：插件只处理分类 / 标签 / 文章 / 评论 / 设置，**不读写 `vd_users` 用户表**，管理员账号不会被替换。

## 三、迁移流程（每站三步）

### Step 1 — 源站数据导出（需源服务器权限）

- **laolv.org（WP）**：二选一
  - 后台「工具 → 导出 → 所有内容」→ 下载 WXR XML；
  - 或服务器上 `mysqldump` 导出 WP 库 SQL（全量、含评论，推荐）。
- **xuecha.org（Typecho）**：二选一
  - 后台「控制台 → 数据备份」导出；
  - 或服务器上导出 Typecho 库 SQL（推荐）。
- 导出后先把文件拉到本地做**只读存档**（迁移可回退的第一道保险）。

### Step 2 — 目标环境部署 + 导入

1. 目标服务器目录部署 RyeBlog（零依赖，PHP 8.3+，MySQL 单库，复制官方安装包 `download/ryeblog-1.0.0.zip`）。
2. 初始化站点 → 后台启用 `data-import` 插件 → 「数据导入」：
   - 源类型选 WordPress XML / Typecho XML / SQL 自动识别；
   - 勾选：**下载远程图片到本地、保留原 slug、作者映射（选本站管理员）、导入评论**。
3. 导入后跑一遍「修复图片」兜底，确保无残留外链图片。
4. **xuecha.org 启用 Vuecho 文档主题**（已移植：`usr/theme/vuecho/`，见 `docs/themes/vuecho.md`）：
   - 后台「外观」启用「Vuecho 文档主题」（VuePress 风格，侧栏置左 + 正文宽版）；
   - 后台「侧边栏管理」添加「文章目录」模块（自动 TOC，滚动高亮 + 折叠）；
   - 开启「侧边栏固定」。
   - laolv.org 按原站风格选默认主题（fresh/forest/mint）或后续自定。

### Step 3 — 验证 + 切换

1. **全站回归**（数据正确性敏感，逐项核对）：
   - 文章 / 独立页面 / 分类 / 标签 / 评论数量与源站一致；
   - 抽查文章页 URL（slug 保留，应与原站路径一致）；
   - 图片全部本地可访问（HTTP 200，非 404）；
   - 分类页 / 标签页 / 搜索可正常命中。
2. 按 RyeBlog 主题重建版式：首页、导航菜单、友情链接、SEO 元信息。
3. **切换**：域名不变——如换服务器则改 Cloudflare DNS 记录指向新服务器；同服务器则改目录/伪静态即可。
4. **回退保险**：原站数据与旧部署保留至少 1 个月，确认稳定后再清理。

## 四、风险与对策

| 风险 | 对策 |
|---|---|
| 文章 URL 变化导致 404 | 导入保留原 slug；切换后抽查关键 URL |
| 图片外链失效 | 导入时本地化 + 导入后「修复图片」兜底 |
| 主题样式不迁移 | 用 RyeBlog 主题重建；xuecha 文档站复用其文档主题样式（RyeBlog 主题开发能力已具备） |
| 评论作者名错乱 | 作者映射统一归属，不触碰登录账号 |
| 后台设置（菜单/友链/SEO） | RyeBlog 后台重新配置，白名单设置随导出可带 |
| 原站数据丢失 | 导出文件本地存档 + 旧部署保留 1 个月回退窗口 |

## 五、执行顺序建议

1. **先迁 xuecha.org**：Typecho 文档站，数据模型简单（contents/metas/relationships/comments 四表），风险低，先跑通全链路；
2. **再迁 laolv.org**：WordPress 内容多、插件生态复杂（Site Kit 等），导入后需重点核对插件相关数据（短代码、自定义字段按需取舍）。

## 六、案例收录动作（迁移完成后）

2. 描述标注基于 RyeBlog + 所用主题名；
