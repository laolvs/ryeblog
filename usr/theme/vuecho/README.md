# Doc 文档主题（RyeBlog）

VuePress 风格三栏文档主题。设计参考 Typecho 主题 [Vuecho](https://github.com/matsuzaka-yuki/Vuecho)（MIT License），并结合 RyeBlog 架构重写。

## 特性

- **三栏文档式阅读**：左侧文档目录树 + 中栏正文 + 右侧页内目录（TOC，可收起）
- **首页文档封面**：Hero（品牌 logo + 标题 + 双按钮）+ 特性卡片 ×3 + 学习目录（按发布时间由旧到新）
- **文档分类树**：按后台分类管理顺序展示，当前分类自动展开，点击可展开/收起；分类带 📁、文章带 📄 图标
- **移动端适配**：顶栏（logo + 搜索 + 三横按钮）、抽屉式目录、正文上方可折叠目录卡片、右下 UX 工具栏
- **右下 UX 工具栏**：🌙 夜间模式 / Aa 字体大小三档 / 📖 阅读模式（隐藏左右栏）
- **markdown 渲染**：标题 / 加粗 / 列表 / 引用 / 代码块（轻量语法高亮）全套支持
- **列表页同风格**：分类 / 标签 / 搜索页复用内容页骨架（左树 + 右列表）

## 安装

- 后台「外观 → 云端主题」一键安装，或上传 ZIP 安装
- 自定义：放入 `usr/theme/vuecho/`，后台「外观」激活

## 后台编辑

后台「外观 → 主题管理 → ✏️ 编辑」：
- **外观配置**：首页 Hero 文案、双按钮、特性卡、学习目录标题（保存即生效）
- **文件编辑**：在线编辑主题模板 / 样式 / 脚本（PHP 文件保存前自动语法校验）

## 建议配置

- 后台「站点设置 → 首页宣传区（文档主题）」：Hero 副标题、双按钮、3 条特性
- 文章页左侧目录自动生成（无需额外模块）

## 文件

| 文件 | 说明 |
|---|---|
| home.php | 首页模板（Hero + 特性 + 学习目录） |
| post.php | 文章/独立页模板（三栏：左树 + 正文 + 右 TOC） |
| list_common.php | 列表页公共骨架（分类/标签/搜索） |
| category.php / tag.php / search.php | 列表页模板 |
| theme.css | 主题样式（含移动端、夜间模式变量） |
| theme.js | 分类树交互 + TOC 滚动高亮 + UX 工具栏 + 代码高亮 |
| assets/xuecha.png | 品牌 logo（可替换） |
